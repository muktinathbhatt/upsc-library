# UPSC Library

A personal UPSC study library containing structured Economics, Geography,
History, and Political Science & International Relations collections.

## Repository contents

- `Economics-Library/` — Economics books and exam practice
- `Geography-Library/` — Geography books, map work, and exam practice
- `History-Library/` — History books and exam practice
- `PSIR-Library/` — complete PSIR Optional Paper I and II books, PYQ themes,
  current-affairs method, and answer-writing practice
- `NCERT/` — source study material
- `quotes,terminology etc.xlsx` — working notes

The website is deployed automatically whenever the `main` branch is updated.
